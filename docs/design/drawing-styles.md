# Drawing styles

The compact Standard / Hand-drawn selector lives in the View toolbar. Individual / Consistent variation, Single / Double strokes and Looseness live in Preferences > Appearance in the Hand-drawn style group for the current schematic. The group is enabled only for Hand-drawn; switching to Standard retains its saved values. OK applies all three settings as one undoable document edit; Cancel discards them. These are document settings rather than application defaults. Individual + Single preserves the original hand-drawn appearance. Style changes use document snapshot undo/redo and mark the document modified.

Format v13 adds drawingLooseness, a finite number from 0 to 3 (shown as 0–300% in Preferences). Older drawings default to 1 (100%), retaining the original hand-drawn appearance. At zero, paths retain exact geometry; increasing looseness scales line and curve deviations while preserving all original anchors. Merely opening and accepting Preferences preserves any finer saved precision.

Format v12 introduced drawingStyle to be standard or hand-drawn, drawingVariation to be individual or consistent, and drawingStrokes to be the integer 1 or 2. Version 11 retains its drawing style and defaults to Individual + Single. Versions 1–10 load as Standard. Newer formats are rejected by older builds. Clipboard insertion adopts the destination document style; it does not change that document setting.

The application-layer SymbolRenderer produces deterministic vector paths from a fixed integer seed derived from the component identity and primitive order, or wire identity. Consistent variation instead uses an FNV-1a hash of the UTF-8 symbol ID with the primitive order; identical symbol instances share local artwork regardless of position/rotation/mirroring. Wires retain individual variation. Double strokes add a second deterministic outline with the same anchors. Each filled primitive is filled once using the primary path, then both outlines are drawn without fills. Hit shapes include the primary fill and both stroked outlines. Symbol styling happens in local coordinates before rotation/mirroring/translation. Line segments receive bounded smooth lateral variation; cubic curves receive small control-point offsets. Original anchors, closed outlines and fill rules are retained. Scene item bounds include the resulting paths, so SVG export includes the variation and its normal margin.

The document geometry stays exact. Wire endpoints, corners, branches, snapping and electrical identities do not move. Junction dots, labels, note boxes and palette previews retain their normal appearance. Splitting a wire or copying an object allocates new identities and may change its stroke variation in Individual mode. Individual object overrides and handwriting fonts are deferred.

Validation covers persistence and legacy defaults, invalid style values, undo/redo, Preferences acceptance/cancellation and undo, toolbar style synchronization, deterministic vector paths and anchors, unchanged topology, SVG reload, export bounds and representative render sheets including valves, all variation/stroke combinations, consistent instance artwork, filled-body painting/hit areas and double-stroke SVG output.
